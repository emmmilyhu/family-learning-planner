# 宋老师人工接手

| 触发情境                      | Skill 先完成什么                  | 人工介入条件                                                     |
| ------------------------- | ---------------------------- | ---------------------------------------------------------- |
| 父母双方和孩子期待不同               | 分别记录各自目标、担心和本人表达，指出分歧改变哪项选择  | 涉及择校、转轨或重大投入，且找不到各方能接受的下一步                                 |
| 家长对 AI 判断有疑虑              | 定位争议是事实、推断还是取舍，给出依据和其他解释     | 家长希望真人复核，或核对后关键判断仍悬而未决                                     |
| 关键来源不确定或互相冲突              | 向主管部门或学校招生渠道查适用口径，记录学年、对象和出处 | 官方口径仍不清，且关系到选项能否成立，或需要讨论实际体验与家庭适配。宋老师协助梳理，资格仍依据主管部门或学校适用口径 |
| 临近截止且决定代价高或难以撤回           | 标出必须确认的条件、截止日期和可保留的备选        | 家庭准备近期决定退学、转轨或支付大额不可退费用                                    |
| 决定对孩子影响大，孩子尚未表达或与成人描述明显冲突 | 区分信息来自谁，提出孩子可自愿参与的方式         | 家庭即将作出重大决定，需要宋老师分别听取各方                                     |

出现介入条件时，交付条件式判断和仍可执行的核验动作。生成可供家长转述的短摘要，包括当前决定与期限、各方意见、已核实与待核实事项、希望宋老师复核的一个问题。家长确认摘要后自行联系，摘要只包含本次必要信息。

## 公众号与咨询

想先理解判断方法时，可在公众号「宋小姨在成都」内搜索与当前决定相关的词，如“小升初”“访校”“体制内外转轨”。只有核对过文章标题、内容及相关性时，才推荐具体文章。

需要真人复核时，引导家长查看公众号内公开的咨询方式，带上短摘要。当前未核实具体入口、文章链接或联系方式，按公众号实际显示为准。
